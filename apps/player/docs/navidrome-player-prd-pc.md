**版本**：1.1  
**日期**：2026-03-02  
**平台**：macOS（当前代码主验证）/ Windows / Linux（桌面端形态规划）

## 1. 文档目标

本文件定义 Navidrome Player 在 PC 端的最新功能范围、实现状态与设计覆盖，覆盖：

1. 当前代码已实现能力（现状）。
2. 当前 UI 设计覆盖（`01~17` 页）。
3. Phase 2/3/4 的未落地开发项。

---

## 2. 信息架构（PC）

## 5. 与阶段规划对齐（PC）

## 6. 验收标准（PC）

1. 页面覆盖：`01~17` 页面均可在设计稿中定位。
2. 导航一致：所有页面导航顺序固定为 `首页 > 音乐库 > 搜索 > 播放列表 > 设置`。
3. 功能映射：PRD 关键模块都能在 UI 中找到对应页面或区块。
4. 代码对齐：已实现能力与 UI 表达一致，不制造“伪已实现”认知。
