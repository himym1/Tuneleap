# 功能文档：Navidrome Player（移动端）

**版本**：1.0  
**日期**：2026-02-28  
**平台**：Android / iOS（移动端形态）  
**设计稿**：`docs/designs/pencil/navidrome/navidrome-mobile.pen`

---

## 1. 文档目标

本文件定义 Navidrome Player 在移动端的功能范围、实现状态与后续规划，覆盖：

1. 当前已实现能力（代码现状）。
2. 已有 UI 设计覆盖（Pencil `.pen`）。
3. 未实现但已规划的功能（Phase 2/3/4）。

---

## 2. 移动端产品目标

1. 让用户在手机上快速完成连接、找歌、播放闭环。
2. 通过底部导航与全屏播放页提升单手操作效率。
3. 保证后台播放、锁屏控制和通知栏控制的稳定性。
4. 在网络不稳定时逐步支持离线播放能力。

## 7. 验收标准（移动端）

1. 首次连接 3 分钟内可完成并开始播放。
2. 切后台后可稳定播放，锁屏控制与应用状态 1 秒内一致。
3. 播放页拖拽进度误差小于 1 秒。
4. 下载后离线场景可播放已缓存内容。
5. 关键页面完整：首页、音乐库、搜索、播放器、播放列表、下载、设置。
