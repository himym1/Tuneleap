# 功能文档：Navidrome Player（PC 端）

**版本**：1.0  
**日期**：2026-02-28  
**平台**：macOS / Windows / Linux（桌面端形态）  
**设计稿**：`docs/designs/pencil/navidrome/navidrome-pc.pen`

---

## 1. 文档目标

本文件定义 Navidrome Player 在 PC 端的功能范围、实现状态与后续规划，覆盖：

1. 当前已实现能力（代码现状）。
2. 已有 UI 设计覆盖（Pencil `.pen`）。
3. 未实现但已规划的功能（Phase 2/3/4）。

---

## 2. PC 端产品目标

1. 在大屏场景提供高效率浏览和播放体验。
2. 通过左侧导航 + 右侧内容区保持信息密度与可达性平衡。
3. 支持后台播放与桌面快捷键，降低操作成本。
4. 为后续离线、均衡器、多服务器等高级能力预留交互结构。

---

## 3. 信息架构（PC）

### 3.1 一级导航

- 首页（Home）
- 音乐库（Library）
- 搜索（Search）
- 播放列表（Playlists，规划中）
- 设置（Settings）

### 3.2 全局区域

- 左侧固定导航栏（NavigationRail 风格）
- 底部或侧栏迷你播放器（MiniPlayer）
- 可展开播放器页（Player）

---

## 7. 验收标准（PC）

1. 播放链路稳定：连续播放 30 分钟不中断。
2. 桌面键盘可用：`Space`、`←/→`、`Cmd+F` 行为一致。
3. 主要页面完整：首页、音乐库、搜索、播放器、播放列表、设置、下载。
4. 设置可持久化：服务器、主题、缓存策略可保存并生效。
5. 功能与 UI 一致：设计稿中的关键交互都能在代码中闭环。
