# Phase 3: 好看 — 视觉体验

> 状态：🔲 未开始 | 功能数：6

## 概述

Phase 3 的目标是提升视觉体验，让应用赏心悦目。

## 功能规格

### 1. 完整播放页

- 目标：精致的全屏播放界面，流畅的展开/收起动画
- 关键元素：大封面（圆角阴影）、歌曲信息、进度条（可拖拽）、控制按钮组
- 动画：MiniPlayer → 全屏 Hero 动画，封面旋转动画（可选）

### 2. 深色/浅色主题完善

- 目标：精细调整两套主题的色彩、对比度、阴影
- 关键文件：`lib/ui/theme/app_theme.dart`
- 规格：Material 3 色彩系统，确保 WCAG AA 对比度

### 3. 封面取色动态主题

- 目标：根据当前播放歌曲封面提取主色调，动态调整播放页配色
- 依赖：palette_generator（Phase 3 引入）
- 交互：切歌时提取封面主色 → 渐变过渡到新配色

### 4. 歌词显示

- 目标：支持内嵌歌词和在线歌词，滚动同步显示
- 数据源：Subsonic getLyrics API + 歌曲内嵌歌词标签
- 交互：播放页切换到歌词视图 → 当前行高亮 → 点击歌词行跳转

### 5. 过渡动画

- 目标：页面切换、列表加载、状态变化的流畅动画
- 关键动画：页面 Hero 过渡、列表 staggered 加载、播放状态切换

### 6. 响应式布局

- 目标：根据屏幕尺寸自适应布局（手机/平板/桌面）
- 断点：compact (<600dp), medium (600-840dp), expanded (>840dp)
- 关键变化：导航方式、网格列数、播放页布局
