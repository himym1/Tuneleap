# Phase 4: 完善 — 高级特性

> 状态：🟡 进行中 | 功能数：6

## 概述

Phase 4 的目标是补充高级特性，提升专业度和完整度。

## 功能规格

### 1. 离线缓存

- 当前：已支持歌曲下载、本地文件回退播放、下载列表展示
- 现状实现：文件系统存储 + `SharedPreferences` 持久化已完成任务
- 待完善：暂停/恢复/重试策略、专辑批量下载、更完整的缓存索引

### 2. 收藏同步

- 当前：已具备收藏页、歌曲收藏 Provider、专辑/艺术家收藏入口
- API 接口：`getStarred2`、`star`、`unstar`
- 待完善：统一状态源、失败回滚细节与接口稳定性校验

### 3. Scrobble 统计

- 当前：已在播放链路中自动上报播放记录
- API 接口：`scrobble`
- 交互：歌曲播放超过 50% 或 4 分钟后自动上报，已包含去重保护
- 待完善：失败重试、状态展示与策略配置

### 4. 音质选择

- 当前：已支持原始/高/中/低等档位，并映射到 `maxBitRate`
- 实现：`stream` URL 添加 `maxBitRate` 参数
- 交互：设置页选择音质，影响后续播放请求

### 5. 键盘快捷键

- 当前：已接入桌面端基础快捷键
- 快捷键：空格播放/暂停，`Cmd+←/→` 上下曲，`Cmd+1~5` 导航，`Cmd+F` 搜索，`Cmd+P` 打开播放器
- 实现：`Shortcuts` + `Actions`
- 待完善：输入焦点冲突处理与更多系统级快捷键

### 6. 多服务器支持

- 当前：已支持添加、编辑、删除、切换当前服务器
- 交互：服务器列表页 → 添加/编辑/删除/切换
- 存储：`SharedPreferences` 存储服务器列表，`flutter_secure_storage` 存储密码
- 待完善：每服务器更细粒度的偏好与缓存隔离
