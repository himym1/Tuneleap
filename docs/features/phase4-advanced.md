# Phase 4: 完善 — 高级特性

> 状态：🔲 未开始 | 功能数：7

## 概述

Phase 4 的目标是补充高级特性，提升专业度和完整度。

## 功能规格

### 1. 离线缓存

- 目标：下载歌曲到本地，支持离线播放
- 依赖：drift (SQLite) 索引 + 文件系统存储
- 交互：长按歌曲/专辑 → 下载 → 下载管理页 → 离线播放

### 2. 收藏同步

- 目标：收藏状态与服务端双向同步
- API 接口：star, unstar
- 交互：本地收藏操作 → 同步到服务端 → 启动时拉取最新状态

### 3. Scrobble 统计

- 目标：上报播放记录到 Navidrome，支持播放统计
- API 接口：scrobble (submission=true/false)
- 交互：歌曲播放超过 50% 或 4 分钟 → 自动上报

### 4. 音质选择

- 目标：支持选择音频质量（原始/高/中/低）
- 实现：stream URL 添加 maxBitRate 参数
- 交互：设置页选择音质 → 影响后续所有播放请求

### 5. 均衡器

- 目标：音频均衡器调节（低音/中音/高音）
- 依赖：just_audio 的 AndroidEqualizer / 平台原生实现
- 交互：设置页 → 均衡器开关 → 预设选择 / 自定义频段

### 6. 键盘快捷键

- 目标：macOS 桌面端键盘快捷键支持
- 快捷键：空格(播放/暂停), ←→(上下曲), ↑↓(音量), Cmd+F(搜索)
- 实现：RawKeyboardListener 或 Shortcuts widget

### 7. 多服务器支持

- 目标：支持配置多个 Navidrome 服务器，快速切换
- 交互：设置页 → 服务器列表 → 添加/编辑/删除/切换
- 存储：SharedPreferences 存储服务器列表
