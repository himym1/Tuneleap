# Aegis Project Workspace

This directory stores reviewable product/architecture baselines, approved design specifications, and implementation plans for non-trivial work in `navidrome_player`.

Authority order for this workspace:

1. Current explicit user decision
2. Project instructions and accepted ADRs
3. Approved specs under `specs/`
4. Baseline snapshots under `baseline/`
5. Implementation plans and evidence

Workspace records guide implementation but do not replace executable tests, ADRs, or fresh verification.
